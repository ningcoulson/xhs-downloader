# XHS Downloader

This is a [Next.js](https://nextjs.org) project designed to download images and videos from Xiaohongshu (Little Red Book).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- Parse Xiaohongshu note links (images and videos).
- Batch download all images.
- Proxy support to bypass referrer checks.
- Clean, responsive UI.
