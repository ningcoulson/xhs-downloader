# 小红书下载器 - 微信小程序使用指南

## 📱 快速开始

### 1. 导入项目
1. 打开微信开发者工具
2. 选择"导入项目"
3. 项目目录选择：`xhs-miniprogram`
4. AppID：使用测试号或您的小程序 AppID

### 2. 配置网络权限
在微信开发者工具中：
1. 点击右上角"详情"
2. 切换到"本地设置"
3. ✅ 勾选"不校验合法域名..."

### 3. 编译运行
点击左上角"编译"按钮即可运行

**本地开发（同一WiFi）：**
```javascript

```

**Vercel 部署后：**
```javascript

```

## 📝 使用流程

1. **复制链接**
   - 打开小红书APP
   - 找到想要下载的笔记
   - 点击分享 → 复制链接

2. **粘贴解析**
   - 在小程序输入框中粘贴链接
   - 点击"开始解析"

3. **下载保存**
   - **单张图片**：点击图片右下角下载按钮
   - **批量下载**：点击"一键保存全部"按钮
   - **视频**：点击"保存视频到相册"

4. **授权相册权限**
   - 首次下载会请求相册权限
   - 请务必允许，否则无法保存

## ⚠️ 注意事项

### 网络要求
- ✅ 本地开发：需要连接同一WiFi
- ✅ 公网访问：确保后端服务可访问
- ✅ 真机调试：建议使用域名而非IP

### 权限说明
小程序需要以下权限：
- 📷 **相册写入权限** - 保存图片和视频
- 🌐 **网络请求** - 访问后端API

### 常见问题

**Q: 显示"网络错误"？**
- 检查手机是否联网
- 确认后端服务是否运行
- 验证API_BASE地址是否正确

**Q: 文件保存失败？**
- 检查是否授权了相册权限
- 在设置中重新授权小程序

**Q: 图片加载慢？**
- 小红书CDN速度受网络影响
- 建议使用WiFi环境

## 🚀 部署建议

### 生产环境部署
推荐将后端部署到云平台：
- **Vercel**（推荐）：免费、自动HTTPS
- **Railway**：简单易用
- **自建服务器**：需要配置HTTPS证书

### 域名配置
1. 小程序正式发布需要配置合法域名
2. 在微信公众平台配置服务器域名
3. 必须使用HTTPS协议
