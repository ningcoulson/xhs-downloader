## 第一步：注册微信小程序账号

### 1. 访问微信公众平台
👉 https://mp.weixin.qq.com/

### 2. 注册小程序
1. 点击"立即注册"
2. 选择"小程序"类型
3. 填写邮箱、密码
4. 激活邮箱
5. 选择主体类型：
   - **个人**：免费，适合个人开发者
   - **企业**：需要营业执照，功能更多

### 3. 完成信息登记
- 管理员身份验证（微信扫码）
- 填写小程序基本信息
- 获取 **AppID**（非常重要！）

💰 **费用说明**：
- 个人账号：免费
- 企业账号：300元/年认证费（可选）

## 第二步：配置服务器域名（⚠️ 关键步骤）

### ❌ 当前问题
您现在使用的是 `http://xhs.pwcer.com:3000`，这个**不符合微信要求**：
- ❌ HTTP协议（必须用HTTPS）
- ❌ 非标准端口（必须用443端口）

### ✅ 解决方案

#### 方案A：使用 Vercel 部署（推荐，免费）

1. **注册 Vercel 账号**
   ```
   https://vercel.com
   ```

2. **部署后端到 Vercel**
   ```bash
   # 在项目根目录执行
   cd "/Users/ning/ai/XHS Downloader"
   npx vercel login
   npx vercel
   ```

3. **自动获得 HTTPS 域名**
   ```
   https://xhs-downloader.vercel.app
   ```
   或绑定您的域名：
   ```
   https://xhs.pwcer.com
   ```

4. **在微信公众平台配置域名**
   - 登录 https://mp.weixin.qq.com
   - 开发 → 开发管理 → 服务器域名
   - 添加：`https://xhs.pwcer.com` 或 `https://xhs-downloader.vercel.app`

#### 方案B：申请免费 SSL 证书（自建服务器）

如果您想继续使用自己的服务器：

1. **申请 SSL 证书**
   - Let's Encrypt（免费）：https://letsencrypt.org/
   - 阿里云/腾讯云（免费）

2. **配置 Nginx 反向代理**
   ```nginx
   server {
       listen 443 ssl;
       server_name xhs.pwcer.com;
       
       ssl_certificate /path/to/cert.pem;
       ssl_certificate_key /path/to/key.pem;
       
       location / {
           proxy_pass http://192.168.2.185:3000;
           proxy_set_header Host $host;
       }
   }
   ```

3. **路由器端口转发**
   - WAN 443 → LAN 192.168.2.185:443

## 第三步：修改小程序代码

### 更新 API 地址

编辑 `xhs-miniprogram/pages/index/index.js`：

```javascript
// 改为您的 HTTPS 域名
const API_BASE = 'https://xhs.pwcer.com';  // 去掉端口号
```

### 配置项目 AppID

编辑 `xhs-miniprogram/project.config.json`（如果没有则创建）：

```json
{
  "appid": "您的AppID",
  "projectname": "小红书下载器",
  "description": "方便快捷地下载小红书图片和视频",
  "setting": {
    "urlCheck": true,
    "es6": true,
    "enhance": true,
    "compileHotReLoad": true
  }
}
```

## 第四步：上传代码

### 在微信开发者工具中：

1. **登录账号**
   - 右上角 → 登录 → 使用您注册的账号

2. **设置 AppID**
   - 详情 → 基本信息 → AppID

3. **上传代码**
   - 工具栏 → 上传
   - 填写版本号：`1.0.0`
   - 填写项目备注：`首次发布`
   - 点击"上传"

⏱️ **上传后**：代码会出现在微信公众平台的"开发管理"中

---

## 第五步：提交审核

### 在微信公众平台操作：

1. **登录** https://mp.weixin.qq.com
2. **版本管理** → 开发管理 → 开发版本
3. **点击"提交审核"**

### 填写审核信息：

#### 1. 服务类目
选择合适的类目，例如：
- 工具 → 效率
- 生活服务 → 综合生活服务

#### 2. 标签（最多10个）
```
小红书 下载 图片 视频 工具
```

#### 3. 功能页面
- 页面路径：`pages/index/index`
- 功能描述：粘贴小红书链接，下载高清图片和视频

#### 4. 测试账号（可选）
提供测试微信号供审核人员使用

### ⏰ 审核时长
- 正常：1-7天
- 加急：可申请（需要理由）

---

## 第六步：发布上线

### 审核通过后：

1. 版本管理 → 审核版本
2. 点击"发布"
3. 全量发布 → 确认

🎉 **恭喜！您的小程序正式上线了！**

### 分享给用户
用户可以通过以下方式找到您的小程序：
- 微信搜索小程序名称
- 扫描小程序码（公众平台生成）
- 分享给好友/朋友圈

## ⚠️ 重要注意事项

### 1. 内容合规
- ❌ 禁止下载他人原创内容后商用
- ✅ 仅供个人收藏使用
- 建议增加"免责声明"

### 2. 域名要求
- ✅ 必须 HTTPS
- ✅ 必须备案（国内服务器）
- ✅ TLS 1.2 及以上

### 3. 接口安全
考虑添加：
- 访问频率限制
- Token 验证
- IP 白名单

### 4. 隐私政策
微信要求小程序必须有隐私政策，可在小程序中添加一个页面：
```
pages/privacy/privacy
```
