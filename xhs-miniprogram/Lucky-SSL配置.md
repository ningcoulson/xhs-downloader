# Lucky SSL 证书配置指南

- ✅ 反向代理已配置：xhs.pwcer.com:443 → 192.168.2.185:3000

## 配置步骤

### 方案一：使用 Lucky 申请免费证书（推荐）

1. **登录 Lucky 管理面板**
   - 地址：http://192.168.2.1:16601
   - 账号/密码：666/666

2. **进入 SSL/TLS 证书管理**
   - 点击左上角"菜单"
   - 选择"SSL/TLS证书"

3. **申请免费证书**
   - 点击"添加证书"或"申请证书"
   - 选择证书提供商：
     - **Let's Encrypt**（推荐）
     - ZeroSSL
   - 域名：`xhs.pwcer.com`
   - 验证方式：HTTP-01（最简单）
   - 自动续期：开启

4. **应用证书到 Web 服务**
   - 返回"Web服务"
   - 编辑现有规则
   - SSL证书：选择刚申请的证书
   - 保存

### 方案二：暂时使用自签名证书（仅测试）

如果暂时无法申请证书，可以先用自签名证书测试：

1. 在 Lucky SSL 页面生成自签名证书
2. 应用到 Web 服务规则
3. ⚠️ 浏览器会显示"不安全"警告
4. ⚠️ 微信小程序会拒绝连接

### 验证 HTTPS 访问

配置完成后测试：
```bash
curl -I https://xhs.pwcer.com
```

应该看到：
```
HTTP/1.1 200 OK
```

## 注意事项

1. **域名必须解析到公网 IP**
   - 确认：`nslookup xhs.pwcer.com` 返回正确的公网 IP

2. **端口 80 必须开放**
   - Let's Encrypt 使用 HTTP-01 验证需要访问 80 端口

3. **证书自动续期**
   - Let's Encrypt 证书有效期 90 天
   - 需要开启自动续期功能
